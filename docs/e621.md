# e621 분류 데이터

`python tagorg.py fetch`가 `data/source/sources.json`에 기록된 e621 태그 목록을 받습니다. Danbooru와 이름이 같은 태그에는 공통 분류를 적용하고, e621 고유 태그에는 `data/overlay/e621.csv`와 e621의 태그 종류를 사용합니다.

`python tagorg.py stats --site e621`로 분류 현황을 확인할 수 있습니다. 배치 분류에 위키·함의 근거를 사용하려면 e621의 `wiki_pages-*.csv.gz`와 `tag_implications-*.csv.gz` 내보내기 파일을 `work/evidence/e621/`에 둡니다. [e621 분류 지침](classification-guide.md)
