# 크롬 확장

NovelAI 같은 웹 툴의 입력창에서 프롬프트를 고르고 오른쪽 클릭으로 정렬합니다. Python 없이 브라우저 안에서 동작하고, 프롬프트는 브라우저 밖으로 나가지 않습니다.

## 설치

`python tagorg.py fetch`로 원본 목록을 받은 뒤 다음 명령을 실행합니다.

```sh
python tagorg.py extension
```

`extension/data/`에 팩과 프리셋 목록이 생깁니다. 크롬의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 `extension` 폴더를 고르세요. 분류나 배열을 바꾼 뒤에는 이 명령을 다시 실행하고 확장 카드의 새로고침을 누릅니다.

| 옵션 | 뜻 |
|---|---|
| `--no-build` | 빌드하지 않고 기존 `build/tagpack.json.gz` 사용 |
| `--pack 경로` | 다른 팩 파일 사용 |
| `--no-local` | 내 배열(`local/arrangements/`)을 넣지 않음 |
| `--zip 경로` | 설치용 zip도 만듦. 풀어서 같은 방법으로 설치 |

zip에는 태그 데이터가 그대로 들어 있습니다. 다른 사람에게 배포하려면 [데이터 출처와 라이선스](../README.md#데이터-출처와-라이선스)를 먼저 확인하세요.

## 쓰는 법

- **오른쪽 클릭**: 입력창에서 글을 고르고 오른쪽 클릭 → **프롬프트 정렬** → 프리셋. 프리셋은 레이아웃, 내 배열, 패널에서 가져온 배열입니다. 공개판에는 공유 배열이 들어 있지 않으며, `data/arrangements/`에 직접 둔 배열도 목록에 나옵니다.
- **단축키**: `Alt+Shift+O`. 패널의 "단축키에 쓸 프리셋"으로 정렬합니다. 키는 `chrome://extensions/shortcuts`에서 바꿉니다.
- **도구 모음 패널**: 붙여 넣어 정렬하기, 설정(필터·등급·구도 규칙·출력 문법·주석·줄바꿈·추정), 배열 가져오기.

정렬 뒤에는 화면 아래 알림으로 정렬한 수, 뺀 태그, DB에 없는 수, 문법 경고 수를 보여 줍니다. 되돌리기는 입력창의 Ctrl+Z입니다.

| 상황 | 동작 |
|---|---|
| 글을 고르지 않음 | 입력창 전체 |
| 쉼표·줄바꿈·BREAK가 든 부분을 고름 | 고른 부분만. 앞뒤의 빈칸·쉼표는 그대로 둠 |
| 조각 하나만 고름(구분 표기 없음) | 입력창 전체 |
| 고른 부분에서 `{}`·`[]`·`()`·`::` 강조가 잘림 | 바꾸지 않고 알림 |
| 필터로 모두 빠짐 | 바꾸지 않고 알림 |
| 정렬하는 사이 글이 바뀜 | 바꾸지 않고 알림 |

중복 제거와 구도 규칙은 고른 부분 안에서만 판단합니다. 입력 문법은 자동으로 알아내고, 출력은 NovelAI에서는 `nai`, 다른 사이트에서는 입력과 같은 문법입니다(패널에서 고정 가능).

## NovelAI 화면

`novelai.net/image`에서는 입력창 머리글에 버튼이 붙습니다. 끄려면 도구 모음 패널의 "NovelAI 화면에 정렬 버튼 표시"를 끕니다.

- **`⇅ TagOrganize`**: 바로 정렬합니다. 입력창에 고른 글이 있으면 고른 부분만입니다.
- **`▾`**: 대상 입력창, 프리셋, 보이는 입력창 모두 정렬, 미리보기 패널. 프리셋을 고르면 그 프리셋으로 정렬하고 기억합니다.
- **`▤`**: 미리보기 패널(머리글이 좁으면 `▾` 메뉴에서).

대상은 마지막으로 누른 입력창이고, 보이는 입력창만 다룹니다. 입력창 묶음(Prompt·Base Prompt / UC / 캐릭터)마다 프리셋·구도 규칙·추정을 따로 기억합니다. UC는 구도 규칙이 꺼진 채로 시작합니다.

NovelAI 화면이 바뀌어 머리글을 찾지 못하면 버튼을 화면 오른쪽 아래에 띄웁니다. 오른쪽 클릭 메뉴와 단축키는 그대로 동작합니다.

### 미리보기 패널

페이지를 막지 않는 창입니다. 제목 줄로 옮기고, 오른쪽 아래 모서리로 크기를 바꾸고, 접을 수 있습니다.

**붙이기**를 누르면 왼쪽 칸 바로 옆에 붙고 그림 칸이 남은 폭으로 줄어들어, 생성한 그림을 가리지 않습니다. 오른쪽 가장자리를 끌어 폭을 바꾸고, **띄우기**로 돌아옵니다. 접거나 닫으면 그림 칸이 원래 폭이 됩니다. 창이 좁아 그림 칸이 충분히 남지 않으면 떠 있는 창으로 돌아갔다가, 넓어지면 다시 붙습니다.

- 원본 고정이 꺼져 있으면 입력창에 쓰는 대로 미리보기가 따라옵니다. 빠지는 태그는 흐린 취소선, 추정한 태그는 기울임, 덮어쓰기로 넣은 태그는 굵게 표시합니다.
- 크롭·시점·시선은 프롬프트의 해당 태그를 고른 태그로 바꿉니다. 원본 고정이 꺼진 묶음은 패널을 닫으면 잊고, 버튼 정렬에는 쓰지 않습니다.
- 시점은 여러 개를 고를 수 있습니다(from behind + from side 등). 서로 부딪치는 시점(front view와 from behind, from above와 from below 등)은 켜는 순간 앞의 것이 꺼지고, multiple views를 켜면 함께 고를 수 있습니다.
- 시선은 여러 개를 고를 수 있고, 함께 쓸 수 없는 태그(looking up과 looking down 등)는 켜는 순간 꺼집니다. 지금 크롭·시점과 맞지 않는 시선(straight-on의 looking back 등)은 목록에서 사라집니다.
- facing 시선을 고르면 눈이 떠 있어야 성립하는 태그(yellow eyes, tsurime, large eyes 등)가 구도 규칙으로 빠집니다. closed eyes, blindfold처럼 눈이 안 보이는 태그와 눈썹은 남고, looking 시선을 함께 고르면 빼지 않습니다.
- **적용**을 눌러야 입력창이 바뀌고, 입력창 전체에 넣습니다. 되돌리기는 입력창의 Ctrl+Z입니다.
- **적용 후 생성**: 결과를 입력창에 넣고 NovelAI의 Generate를 한 번 누릅니다. 버튼에 Anlas 비용을 함께 보여 주고, 원본을 켠 다른 보이는 입력창도 같이 넣습니다. 넣을 것이 없으면 **생성**으로 바뀝니다. 입력창을 직접 고쳤으면 그 변경이 사라지지 않게 누르지 않고 알립니다. 누른 뒤에는 NovelAI 버튼이 돌아올 때까지 잠그고, 자동으로 다시 누르지 않습니다. NovelAI 화면에서 버튼을 찾지 못하면 보이지 않습니다.
- **원본 고정**을 켜면 입력창별 원본을 보관하고, 원본에서 정렬한 결과만 적용합니다. 원본은 **원본** 탭에서 고칩니다. 배열 편집 중에도 같은 탭을 쓰고, UC에는 없습니다. 원본과 켜진 묶음의 칩 선택은 패널을 다시 열거나 페이지를 새로고침해도 남습니다.
- 입력창을 직접 고치면 적용 시 사라질 변경을 경고합니다. 원본 탭의 **입력창에서 가져오기**를 두 번 누르면 현재 글로 원본을 바꿉니다. NovelAI 입력창의 태그 자동완성을 쓰며 고칠 때도 이렇게 가져옵니다. 원본 고정을 끄면 입력창 글을 쓰고, 보관한 원본은 다음에 켤 때 다시 씁니다.

### 배열 편집

패널의 **배열 편집**을 누르면 청크 화면과 색 미리보기가 나란히 나옵니다.

- **청크 끌기**: 줄 안 순서를 바꾸고, 줄 사이·맨 아래에 놓으면 새 줄입니다.
- **줄 끌기**: 줄 번호나 줄의 빈 자리를 끌면 줄째 위아래로 옮깁니다. 줄 끝의 빈 줄도 함께 옮겨 갑니다.
- **빈 줄**: 청크 칸 옆의 **+** 를 줄 사이로 끌어다 놓습니다. 누르면 맨 아래 빈자리에 넣습니다. 점선 띠는 끌어서 다른 줄 사이로 옮깁니다.
- **?**: 조작 요약을 보여 줍니다.
- **▸ 또는 더블클릭**: 서브(멤버)를 펼칩니다. 서브를 끌어 순서를 바꾸거나, 다른 청크에 넣거나, 청크 밖에 놓아 새 청크로 뺍니다.
- **우클릭**: 줄바꿈·위/아래에 빈 줄 넣기·앞 줄과 합치기·숨기기·이름/색·다른 청크에 합치기·커스텀 청크 편집. 줄의 빈 자리나 줄 번호에서는 그 줄 아래에 빈 줄을 넣고 뺍니다. 점선 **빈 줄** 띠에서는 빈 줄을 뺍니다.
- **+ 커스텀**: 태그·패턴으로 고른 토큰을 모으는 청크. **⋯**: 배열 이름, 추정 규칙, JSON 보기·붙여넣기, 모두 펼치기·접기.
- **되돌리기·다시 실행**: 단추나 패널 안의 Ctrl+Z·Ctrl+Y.

**저장**하면 확장 안(`chrome.storage.local`)에 "가져온 배열"로 남고, 프리셋 목록과 메뉴에 바로 보입니다. 레이아웃이나 `extension/data`에 든 배열을 고쳐 저장하면 이름을 물어 새 배열로 저장합니다.

관리 툴과는 **내보내기**(JSON 파일)나 **⋯ → JSON 보기**, **가져오기**로 주고받습니다. 지금 분류 체계에 없는 분류가 든 배열은 열리지 않습니다.

## 권한

권한은 `activeTab`·`scripting`·`contextMenus`·`storage`입니다. 다른 사이트에서는 메뉴나 단축키를 누른 탭에만 들어가고, 사이트 접근 권한(`host_permissions`)은 없습니다. 항상 도는 콘텐츠 스크립트는 `https://novelai.net/*`에만 있고, `/image`가 아닌 화면에서는 아무것도 하지 않습니다.

## 개발

Python 코어(`bmk_tag_organizer_core.py`)의 동작을 바꾸면 `extension/engine/core.js`도 같이 고칩니다. 조작 규칙은 `gui/arrangement.py`와 `extension/editor/model.js`를 같이 고칩니다. `tests/test_extension_core.py`가 두 쪽의 결과를 비교하고, Node가 없으면 건너뜁니다.

`python tagorg.py sync`는 `extension/editor/`의 청크 편집기를 ComfyUI 노드 팩으로도 복사합니다. 두 모듈은 import만으로 아무 일도 하지 않아야 합니다.

실제 크롬 시험은 임시 프로필의 헤드리스 크롬으로 `novelai.net`을 엽니다. 로그인과 생성 요청은 하지 않습니다(Generate 클릭은 NovelAI에 넘기기 전에 가로채 횟수만 셉니다). 크롬 위치는 `CHROME_PATH`로 바꿀 수 있습니다.

```sh
python tagorg.py extension --no-build
node tests/extension/e2e_chrome.mjs
node tests/extension/e2e_nai.mjs
```
